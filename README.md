# MiniGit

MiniGit is a simplified implementation of Git written entirely in C.

The objective of this project is to understand how Git works internally by implementing its core features from scratch.
    -while improving system programming in C.

## Why this project?
    
    -Rather than using Git as a blackbox, this project focuses on understanding how a version control system works internally.

    -By implementing Git's core features from scratch  in c, I aim to strengthen my understanding of: 

        -Filesystems
        -File I/O
        -Error handiling
        -Data structures
        -System programming
        -Git internals
---
